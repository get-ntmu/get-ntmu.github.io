Notes: 

The Vista Teal version is a custom fork of the Consent Dialog that replaces the Grey banner version with the teal so ALL trusted signed Binaries show teal banner not just Microsoft Windows signed ones.. 

The teal banner for non-Microsoft signed binaries uses the yellow shield (as it always was) and microsoft signed ones use the standard UAC shield. I kept this functionality to still allow users to distinguish between them still but without the ugly grey banner! 

*This Also Overwrites Shell32.dll.mun in SystemResources* (Toggleable) This will replace all your ui Icons and the up directory arrow in Explorer with Vista Icons (This only applies to the Vista / Vista Teal variations) 

The custom up arrow for explorer is a green arrow button from vista that was hardly ever used. I rotated it and it looks perfect!
